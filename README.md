# Wehealthy_database

Проект исследования и предиктивного моделирования медицинских данных. Репозиторий содержит Jupyter Notebook с полным циклом анализа: от первичной разведки до построения и оценки модели машинного обучения.

## Описание проекта
Анализ показателей здоровья целевой группы пациентов (или пользователей фитнес-трекеров). Целью является выявление ключевых факторов риска и предсказание целевых метрик (например, индекса массы тела, вероятности развития заболеваний или уровня стресса).

## Структура проекта
-   `analysis.ipynb` — основной файл с кодом исследовательского анализа данных (EDA), визуализациями и обучением моделей.
-   `data/wehealthy.csv` — исходный датасет *(в примере предполагается закрытый доступ к данным)*.
-   `requirements.txt` — список зависимостей Python.
-   `output/` — директория для сохранения результатов (предсказаний, графиков, сериализованных моделей).

## Основные этапы работы
### 1. Загрузка и первичный анализ
*   Импорт библиотек: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`.
*   Изучение структуры данных: типы столбцов, поиск пропусков и статистическое описание признаков.
*   *Пример выявленной проблемы:* наличие пропусков в критически важных показателях (давление, уровень глюкозы).

### 2. Предобработка данных
*   Работа с категориальными признаками (пол, группа крови, образ жизни): применение One-Hot Encoding или Label Encoding.
*   Обработка числовых выбросов (например, физиологически невозможные значения пульса или веса) через перцентильное отсечение.
*   Заполнение пропусков средними/медианными значениями по возрастным группам или интерполяцией временных рядов.

### 3. Создание новых признаков (Feature Engineering)
*   Расчет производных индексов: ИМТ ($BMI = \frac{weight}{height^2}$), отношение талии к бедрам.
*   Нормализация биометрических показателей относительно возрастных норм.
*   Логарифмирование сильно скошенных распределений (например, биохимических маркеров).

### 4. Визуализация
*   Построение тепловых карт корреляций между показателями здоровья.
*   Распределение целевых переменных по полу и возрасту.
*   Географическое распределение данных (если применимо).

### 5. Построение модели
*   Признаки: демографические данные, анамнез, результаты анализов.
*   Целевая переменная: например, `disease_risk_score`.
*   Разделение на обучающую и тестовую выборки (67% / 33%).
*   Масштабирование признаков (`StandardScaler`).
*   Модель: логистическая регрессия или градиентный бустинг (`RandomForestClassifier` / `XGBoost`).

## Оценка и результаты
*   Метрики качества: ROC-AUC, Accuracy, Precision, Recall, F1-score.
*   Результаты (на тестовой выборке):
    *   Базовая модель: AUC $\approx$ 0.75
    *   С добавлением синтетических признаков и обработкой выбросов: AUC $\approx$ 0.82 (улучшение за счет инженерии признаков).
*   Анализ важности признаков (Feature Importance): наиболее значимые факторы риска.

## Как воспроизвести
1.  Установите необходимые библиотеки:
    ```bash
    pip install -r requirements.txt
    ```
2.  Поместите ваш датасет в папку `data/`. Если данные конфиденциальны, убедитесь, что `.gitignore` исключает эту директорию из коммитов.
3.  Запустите все ячейки ноутбука `analysis.ipynb`.

## Технологический стек
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn.
