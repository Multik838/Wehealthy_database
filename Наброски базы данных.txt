CDM с 3-ей формой нормализации
Таблица “Приемы пищи” (Meals) будет содержать следующую информацию:

– ID приема пищи (meal_id)
– ID пользователя (user_id) - ссылка на таблицу Users
– Название блюда (food_name) - ссылка на таблицу Foods
– Количество порции (portion_amount)

Таблица “КБЖУ” (Nutrients) будет содержать следующую информацию:

– Значение КБЖУ (nutrient_value)
– ID записи дневника (meal_id) - ссылка на таблицу Meals
– Примечание (note)

Таблица “Ингредиенты” (Ingredients) будет содержать информацию о каждом ингредиенте:

– ID ингредиента (ingredient_id)
– Название ингредиента (name)
– Единица измерения (measurement)

Таблица “Пищевая ценность” (Nutrient_values) будет содержать данные о пищевой ценности каждого ингредиента:

– ID значения пищевой ценности (nutrient_id)
– Пищевая категория (nutrient_category)
– Название (name)
– Единицы измерения (units)
